# Koffer

Koffer is a local-first Linux desktop application for discovering, auditioning, organizing, classifying, preparing, and safely maintaining large audio sample libraries.

## Repository status

The product definition is complete enough to execute. Development is **authorized through Dreadnought only**.

Do not begin by inventing architecture or asking the owner to restate the product. The repository contains the product contract, screen set, engineering architecture, database model, execution order, quality gates, packaging plan, and Dreadnought operating rules.

## Start here

1. [docs/INSTRUCTIONS.md](docs/INSTRUCTIONS.md) — end-to-end mission and execution contract.
2. [docs/INDEX.md](docs/INDEX.md) — complete documentation map.
3. [docs/AGENTS.md](docs/AGENTS.md) — mandatory contributor and agent rules.

The single sentence mission is:

> Build the documented Koffer product end-to-end as a production-ready Linux AppImage, using Dreadnought as the sole canonical execution/control plane, and do not stop at scaffolding, demos, placeholders, or partial screen coverage.

## Product boundary

Koffer is an audio sample library and preparation workbench. It is not a DAW, sequencer, cloud sample service, marketplace, or browser application.
