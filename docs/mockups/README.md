# Koffer UI Mockups

These mockups are low-fidelity planning artifacts.

They establish information hierarchy, pane relationships, primary actions, expected density, and broad dark-theme direction.

They do **not** establish final branding, final colors, exact typography, production icons, pixel-perfect spacing, or final control dimensions.

## Mockups

### [Library Browser](library-browser.svg)
Primary three-pane library view with navigation, search/filtering, result rows, and a selected-sample Inspector.

### [Sample Inspector](sample-inspector.svg)
Focused preparation view for waveform work, playback, trim, envelope, pitch, and render/export.

### [Import Review](import-review.svg)
Review step for newly discovered files, suggested classifications, and Reference/Copy/Move decisions.
