# Koffer UI Mockups

These SVGs are the complete structural mockup set for the documented Koffer end state.

They are **visual product references**, not loose inspiration. They establish:
- screen inventory;
- layout and pane relationships;
- information hierarchy;
- dominant actions;
- navigation placement;
- dark-theme direction;
- desktop density;
- safety messaging;
- workflow grouping.

Exact platform font metrics and widget chrome may differ in implementation, but critical information and actions must not disappear.

## Reference size

All mockups use a 1440 × 900 desktop reference window.
